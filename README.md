# Приложение "Визитка"

## Описание
Это приложение представляет собой мою цифровую визитку, где отображены мои ФИО, специальность и контакты для связи.

## Технологии
- Kotlin
- Android SDK

## Установка
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/1nan1eee/business-card.git
   ```
2. Откройте проект в Android Studio.
3. Убедитесь, что у вас установлены зависимости и SDK для Android.
4. Запустите приложение на эмуляторе или реальном устройстве.
